# ETF Market — 中国沪深场内 ETF 全市场监控终端 V1.0

专业金融终端风格的沪深场内 ETF 行情监控网站：全市场概览、分类看板、全量列表筛选、本地自选、个券详情与技术指标。

数据真实性优先。行情与资料来自**东方财富公开接口**，页面会标明来源、行情时间和是否可能延迟。本项目**不会用模拟数据冒充真实行情**；拿不到的字段显示为「—」并说明原因。

## 启动方法

需要 Node.js 18+（开发时使用 Node 24 验证）。

```bash
cd etf-market
npm install
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。

其他命令：

```bash
npm run build    # 生产构建
npm run start    # 构建后启动
npm run typecheck
npx tsx scripts/verify-data.ts   # 直接请求东方财富，打印全市场数量与抽样字段
```

首次打开全市场页时，服务端会分页拉取全部沪深场内 ETF（2026-11-10 合并板块实测 1719 只），并缓存基金 F10 资料、最新公布净值与 IOPV。F10 与官方净值会在首屏尽量补齐；折溢价按（最新价 − 最新公布单位净值）/ 净值计算，并标注净值日期。缺少公布净值时折溢价显示为缺失，不会用 IOPV 或昨收代替。IOPV 在后台补全，仅用于 IOPV 列与详情展示。

## 部署

### Vercel

1. 将本目录作为根目录导入 Vercel。
2. 构建命令：`npm run build`；输出：Next.js 默认。
3. 无需填写 API Key。
4. Serverless 环境下本地 `.data` 缓存可能无法持久化，进程会在内存中重新缓存 F10 / 官方净值 / IOPV。冷启动后首次拉取净值可能需要约 1–2 分钟，之后同一进程可直接读内存缓存。

### 通用 Node 服务器

```bash
npm install
npm run build
npm run start -- --port 3000
```

可用反向代理（Nginx / Caddy）将 3000 端口暴露为 HTTPS。

## 环境变量

无需密钥。可选：

| 变量 | 说明 | 默认 |
| --- | --- | --- |
| `ETF_CACHE_DIR` | F10 / 官方净值 / IOPV / 上一交易日收盘快照文件缓存目录 | 项目下 `.data` |

这些公开接口不需要 Token，前端也不会携带任何密钥。

## 已实现功能（V1.0）

- 全市场概览：数量、已披露总规模、总成交额、涨跌平家数与分布、涨幅/跌幅/放量上涨/放量下跌 TOP 5、热点主题（按跟踪指数归类，成交额加权）
- 分类看板：宽基 / 行业 / 主题 / 跨境 / 商品 / 债券 / 货币 / 其他（依据 F10 `FUND_TYPE` + 跟踪指数，不单靠名称）
- 沪深场内 ETF 全量动态清单（按东方财富股票/货币/跨境/黄金/商品/债券等板块合并分页拉取，不写死名单；2026-11-10 实测约 1719 只）
- 搜索、组合筛选、列显示/隐藏、全字段排序、分页、导出当前筛选 CSV、加自选
- 自选：本地 `localStorage`、分组、手动排序、价格/涨跌幅监控、跳转详情
- 详情页：行情、以最新公布净值计算的折溢价（标注净值日期）、IOPV、分时/日/周/月 K、MA/MACD/RSI/BOLL/VWAP（由 K 线或分时计算）、基金信息、历史涨跌幅、风险提示
- 页眉展示数据来源、行情时间（Asia/Shanghai）、交易时段状态、资料、净值与 IOPV 覆盖率
- 顶栏「历史市场 / 今日市场 / 设置」：「今日市场」为现有 15 秒轮询的实时行情；「历史市场」可选择任一已结束的沪深交易日查看收盘快照（不是日历昨天，也不会把尚未收盘的今天当作历史行情）。选中日期的快照会下载到服务端本地（内存 + `.data` 文件），并同步到浏览器 IndexedDB，同一天再次打开直接读缓存。可在「设置」中查看已缓存日期、勾选删除或全部删除。周末与节假日没有收盘行情，不会编造数据。
- 列表默认列包含「今年涨跌幅」「运作费率」

## 当前数据源限制

- 主源：东方财富公开行情（`82.push2` / `push2` / `push2delay` 回退）和 F10（`datacenter-web`）。**不是交易所官方实时馈送**。
- 全量清单板块（2026-11-10 实测）：`MK0021` 股票 ETF、`MK0022` 货币 ETF、`MK0023` 跨境 ETF、`MK0024` 黄金 ETF、`MK0827` 商品 ETF、`MK0828` 债券 ETF。仅用 `MK0021+MK0022` 会漏掉跨境/商品/债券，约 1404 只；合并后约 1719 只。页面按该合计动态分页拉取。
- clist 的 `f441` / `f402` 经抽样更接近净值及相对净值的偏离（例如 159941 的 `f441=1.396` 与 NAV 一致，不是 IOPV 1.621），**不能**当作 IOPV 或基于 IOPV 的折溢价。
- 交易时段数据可能延迟；收盘后为日终行情。
- 今日市场折溢价与常见券商口径一致：`(最新价 − 最新公布单位净值) / 净值`。净值取自东方财富 `lsjz` 的最新一条 `DWJZ`，必须标注净值日期；不会用 IOPV、`stock/get` 的 `f131`、昨收或估值填补。`clist` 没有可用的官方净值字段。IOPV 仍来自 `stock/get` 的 `f71`，仅作盘中参考。跨境/QDII 净值常滞后 1–2 个交易日，此时溢价是市价相对已公布净值的偏离。
- 基金规模使用 F10 `NEW_SCALE`，并展示 `NEW_SCALE_DATE`。不会把 `clist f20`（现价×份额）标成基金规模。
- 跨境/QDII 的 IOPV、净值可能因海外时差或休市滞后，详情页会提示。
- 已实现跟踪误差无法可靠获取；界面如展示相关文字会标明「合同目标」。
- 名称含「退市/暂停」或最新价缺失时，按终止上市 / 暂停 / 无行情处理，不会用 0 填充价格。
- `fundgz.1234567.com.cn` 估值接口已失效，未使用。
- 今年涨跌幅：今日市场取 clist `f25`（年初至今）。2026-11-11 用 510300、159915、513100、513290 对照日 K（前复权）公式 `(当日收盘 / 上一自然年最后交易日收盘) - 1`，与 `f25` 一致；同期 `f127` 不是该口径，未采用。「历史市场」按同一公式用该收盘日 K 线计算，不会用当天的今年涨跌幅。当年上市、没有上年收盘时，改用上市后最早收盘价；算不出则显示「—」。
- 运作费率 = 管理费率 + 托管费率，分别来自 F10 `DEC_GUANLIFEI` 与 `DEC_TUOGUANFEI`；未接入销售服务费（多数场内 ETF 为 0）。管理费或托管费缺失时显示为「—」。列表和详情只展示运作费率，不再展示分项。查询条件的跟踪指数为下拉列表，选项来自当前市场已披露的指数名称（按数量排序），也可选「未披露跟踪指数」。基金代码请在「搜索代码/名称」中查询。
- 「历史市场」收盘溢价只用与该收盘日相同日期的官方净值；没有同日净值则显示为 —。盘口、量比、IOPV 等盘中字段在收盘快照中为缺失，不会用净值或昨收填补。Vercel 等无持久磁盘的环境里，文件缓存可能在重启后消失，需重新下载；「设置」页会提示这一点。

字段映射详见开发记录 `DATASOURCE_FINDINGS.md`（验证日期：2026-11-10，Asia/Shanghai）。
